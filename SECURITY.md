# Security Policy

## Reporting a Vulnerability

Please do not publish credentials, private information, or sensitive
exploit details in public issues.

For vulnerabilities affecting this project, use a private reporting
channel where available.

Include enough information to reproduce and assess the issue safely.

## Secrets and Sensitive Data

- Never commit passwords, tokens, or private keys.
- Do not include real credentials in test fixtures.
- Review datasets for sensitive information before publication.
- Do not publish confidential security findings.
