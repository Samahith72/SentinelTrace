# Contributing to SentinelTrace

## Development Principles

- Keep changes focused and understandable.
- Follow the existing package structure.
- Write tests for new functionality.
- Document important design decisions.
- Avoid committing generated build output.
- Never commit credentials or private configuration.

## Commit Messages

Use descriptive commit messages.

Examples:

- docs: add initial project documentation
- chore: initialize repository structure
- feat: add project management APIs
- test: add project service unit tests
- fix: correct dependency version matching
