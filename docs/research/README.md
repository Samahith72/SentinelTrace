# SentinelTrace Research

This directory contains the research questions, methodology, experimental design, and evaluation criteria for SentinelTrace.

## Primary Research Question

Can dependency-graph analysis and vulnerability intelligence improve software supply-chain risk prioritisation compared with vulnerability-severity-only ranking?

## Planned Research Activities

1. Review relevant software supply-chain security research.
2. Define the vulnerability and dependency data sources.
3. Establish severity-based prioritisation baselines.
4. Define the proposed scoring method.
5. Specify evaluation datasets and reference labels.
6. Conduct reproducible experiments.
7. Analyse results, limitations, and threats to validity.

Experimental claims will be based on measured results rather than assumptions.
