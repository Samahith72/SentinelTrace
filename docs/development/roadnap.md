# SentinelTrace Development Roadmap

## Phase 0: Repository Initialization

- [ ] Define the initial project specification.
- [ ] Create the GitHub repository.
- [ ] Initialize the local Git repository.
- [ ] Establish the initial directory structure.
- [ ] Add project documentation and configuration files.
- [ ] Create the initial commit and push to GitHub.

## Phase 1: Spring Boot Foundation

- [ ] Generate the Spring Boot application.
- [ ] Configure PostgreSQL.
- [ ] Establish the backend package structure.
- [ ] Implement the initial project entity.
- [ ] Create project CRUD APIs.
- [ ] Add request validation and error handling.
- [ ] Write automated tests.

## Phase 2: Dependency Ingestion

- [ ] Define supported dependency input formats.
- [ ] Parse dependency metadata.
- [ ] Persist dependency records and relationships.
- [ ] Validate malformed and incomplete inputs.

## Phase 3: Vulnerability Intelligence

- [ ] Integrate the OSV API.
- [ ] Identify matching package and version records.
- [ ] Persist vulnerability information and evidence.
- [ ] Test affected-version matching.

## Phase 4: Dependency Graph Analysis

- [ ] Define graph nodes and edges.
- [ ] Build dependency graph representations.
- [ ] Analyse direct and transitive dependencies.
- [ ] Trace paths to vulnerable components.

## Phase 5: Explainable Risk Scoring

- [ ] Implement a severity-based baseline.
- [ ] Define dependency-related risk indicators.
- [ ] Implement the proposed scoring method.
- [ ] Record contributing factors and explanations.

## Phase 6: Security Dashboard

- [ ] Develop the React application.
- [ ] Integrate backend APIs.
- [ ] Visualise dependencies and vulnerabilities.
- [ ] Display risk assessments and explanations.

## Phase 7: Research Evaluation

- [ ] Define the experimental dataset.
- [ ] Establish reference labels and baselines.
- [ ] Evaluate prioritisation performance.
- [ ] Measure processing time and scalability.
- [ ] Document limitations and reproducibility.

## Phase 8: Documentation and Release

- [ ] Complete architecture documentation.
- [ ] Document API endpoints.
- [ ] Publish setup instructions.
- [ ] Report experimental results.
- [ ] Prepare a technical report.
